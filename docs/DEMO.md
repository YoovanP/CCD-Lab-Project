# Phase 5 demo checklist
Target duration: 5–8 minutes, after all mandatory phase gates pass.
1. Explain fluctuating traffic and the local architecture.
2. Show /docs with positive and negative real sentiment predictions.
3. Show Deployment, Service, healthy Pods, HPA and working CPU metrics.
4. Run sustained load; show measured CPU and additional ready replicas.
5. Reduce load; show scale-in after stabilization.
6. Present actual throughput, mean/p95 latency, errors and hardware limitations.
7. Show a successful GitHub Actions run.
8. Demonstrate optional integrations only if implemented and tested.
9. Run documented local cleanup and verify resources are removed.
Record each team member's contribution. Do not claim cloud deployment from emulator results.
